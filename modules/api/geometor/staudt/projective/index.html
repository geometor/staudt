geometor.staudt.projective.assert_straightedge_only(model: geometor.model.Model) → None¶

Assert that model contains zero compass circles (sympy.geometry.Circle).

Von Staudt’s Geometrie der Lage (1847) and Rechnung mit Würfen (1857) require that every projective construction proceed strictly by unmarked straightedge incidence without metric compass transfers or circle intersections.

Raises:

ProofAssertionError – If any sympy.geometry.Circle exists in model.

Return True iff C lies strictly between A and B (Pasch § 1 Grundsatz V–VIII).

Verifies exact collinearity together with positive inner product of directed segments \(\overrightarrow{AC} \cdot \overrightarrow{CB} > 0\).

geometor.staudt.projective.pair_separates(A: sympy.geometry.Point, B: sympy.geometry.Point, C: sympy.geometry.Point, D: sympy.geometry.Point) → bool¶

Return True iff collinear point-pair {A, B} projectively separates {C, D}.

In Pasch (Vorlesungen § 1 Lehrsätze 19–23 & § 11) and Vailati (1895), four distinct collinear points exhibit cyclic pair separation AB // CD iff the projective cross-ratio \((A, B; C, D)\) is strictly negative. Every harmonic range satisfies \((A, B; C, D) = -1 < 0\) and therefore separates conjugate pairs.

geometor.staudt.projective.projective_abscissa(P0: sympy.geometry.Point, P1: sympy.geometry.Point, Pinf: sympy.geometry.Point | None, X: sympy.geometry.Point) → sympy.Expr¶

Compute von Staudt’s exact projective abscissa (Beiträge § 29, art. 404) of X.

Relative to three distinct collinear reference points \((P_0, P_1, P_\infty)\):

  • When Pinf is a finite projective horizon point on line \([P_0 P_1]\), returns the exact cross-ratio \((P_\infty, P_0; P_1, X)\), mapping \(P_0 \mapsto 0\), \(P_1 \mapsto 1\), and \(P_\infty \mapsto \infty\).

  • When Pinf is None (ideal point at infinity along \([P_0 P_1]\)), returns the exact affine ratio \(\frac{(X - P_0) \cdot d}{d \cdot d}\) with \(d = P_1 - P_0\).

Raises:

ValueError – If reference points coincide, X is not collinear with [P0 P1], or X coincides with Pinf.

geometor.staudt.projective.point_from_abscissa(P0: sympy.geometry.Point, P1: sympy.geometry.Point, Pinf: sympy.geometry.Point | None, coord: sympy.Expr | int) → sympy.geometry.Point¶

Return the exact collinear sympy.geometry.Point whose projective abscissa is coord.

Used strictly for setting up test inputs and checking closed-form algebraic identities; straightedge constructions in geometor.staudt.quadrangle and geometor.staudt.throws never invoke coordinate inversion.
